# Garden Grow
### 모바일 캐주얼 퍼즐 게임 기획서
**Version 0.1**

---

# 1. 게임 개요

## 1.1 장르

- 모바일 캐주얼 퍼즐
- 싱글 플레이
- 스테이지 기반
- 광고 + 인앱결제(IAP) BM

## 1.2 핵심 컨셉

**씨앗을 발아시키고, 꽃에 물을 주어 개화시키며, 개화의 연쇄작용으로 정원을 완성하는 퍼즐 게임**

플레이어는 색상이 다른 씨앗과 제한된 횟수의 색상별 물뿌리개를 이용해 모든 꽃을 개화시켜야 한다.

핵심 재미는 직접 꽃을 하나씩 선택하는 것이 아니라,

> **어떤 색의 물뿌리개를 어떤 순서로 사용할 것인가**

를 판단하는 데 있다.

## 1.3 핵심 키워드

> **Bloom → Unlock → Expand**

꽃이 개화하면 주변 씨앗이 발아하고, 새롭게 발아한 꽃이 다시 다음 개화의 대상이 된다.

---

# 2. 핵심 게임 플레이

## 2.1 기본 상태

게임 시작 시 모든 타일은 씨앗 상태다.

각 씨앗은 고유한 색상을 가지고 있다.

예:

```text
🌱🔴  🌱🔵  🌱🟡  🌱🔴
🌱🟢  🌱🔴  🌱🔵  🌱🟡
🌱🔵  🌱🟡  🌱🟢  🌱🔴
```

단, 게임 시작 시 특정 위치의 씨앗만 **발아 상태**로 시작한다.

```text
🌱🔴  🌱🔵  🌱🟡

🌱🟢  🌿🔴  🌱🔵

🌱🔵  🌱🟡  🌱🟢
```

---

# 3. 꽃의 상태

꽃은 총 3단계의 상태를 가진다.

### 1단계: 씨앗

```text
🌱
```

- 아직 물을 줄 수 없음
- 주변 꽃의 개화에 의해 발아 상태로 변경될 수 있음

### 2단계: 발아

```text
🌿
```

- 물을 받을 수 있는 유일한 상태
- 자신의 색상과 동일한 물뿌리개가 사용되면 개화
- 개화 시 주변 씨앗을 발아 상태로 변경

### 3단계: 개화

```text
🌸
```

- 물을 다시 받을 수 없음
- 주변 씨앗을 발아시킨 뒤 연쇄작용을 발생시킴
- 퍼즐 진행의 핵심 이벤트

---

# 4. 개화 규칙

발아 상태의 꽃에 같은 색상의 물뿌리개가 도달하면 즉시 개화한다.

```text
🌿🔴
  +
🔴 물뿌리개
  ↓
🌸🔴
```

개화가 발생하면 주변의 씨앗이 발아 상태로 변화한다.

예:

```text
🌱 🌱 🌱
🌱 🌸 🌱
🌱 🌱 🌱
```

↓

```text
🌿 🌿 🌿
🌿 🌸 🌿
🌿 🌿 🌿
```

※ 주변 범위는 **4방향 또는 8방향 중 최종 결정 필요**.

초기 프로토타입에서는 두 방식을 모두 테스트하는 것을 권장한다.

---

# 5. 물뿌리개 시스템

## 5.1 기본 개념

물은 물방울이 아니라 **물뿌리개 아이템**으로 표현한다.

예:

```text
🔴 물뿌리개 × 3
```

숫자는 해당 물뿌리개가 물을 줄 수 있는 횟수를 의미한다.

---

# 6. 물뿌리개 자동 타겟팅

플레이어는 물뿌리개 사용 시 직접 꽃을 선택하지 않는다.

게임이 현재 발아 상태인 꽃 중 물뿌리개와 같은 색의 꽃을 자동으로 탐색한다.

탐색 우선순위는 고정한다.

> **하 → 좌 → 우 → 상**

즉 현재 꽃을 기준으로:

```text
       상
       ↑
   좌 ← ● → 우
       ↓
       하
```

순서로 검사한다.

이 규칙은 모든 플레이어에게 동일하게 적용되며, 레벨 Solver에서도 동일한 deterministic rule을 사용한다.

---

# 7. 물뿌리개 연쇄

물뿌리개에는 사용 횟수가 존재한다.

예:

```text
🔴 × 4
```

사용하면 한 번 물을 주고 끝나는 것이 아니라, **잔여 횟수가 소진될 때까지 자동으로 계속 진행한다.**

예:

```text
🔴 × 4

① 🔴 발아 꽃에 물
   ↓
   개화
   ↓
   주변 씨앗 발아

② 새롭게 발생한 🔴 발아 꽃 탐색
   ↓
   물
   ↓
   개화

③ 다시 🔴 발아 꽃 탐색
   ↓
   물
   ↓
   개화

④ 다시 탐색
   ↓
   물
   ↓
   개화

→ 횟수 0
→ 물뿌리개 종료
```

따라서 물뿌리개 하나는 하나의 **자동 연쇄 실행 명령**으로 볼 수 있다.

---

# 8. 물뿌리개 사용 순서

퍼즐의 핵심은 물뿌리개 내부의 자동 처리보다는 **어떤 물뿌리개를 먼저 사용할 것인가**에 있다.

예:

```text
🔴 × 2
🔵 × 2
🟡 × 1
```

현재 상태에서 🔴을 먼저 사용하면:

```text
🔴 개화
 ↓
주변 씨앗 발아
 ↓
🔵 발아 증가
 ↓
🟡 발아 발생
```

할 수 있다.

반대로 🟡을 먼저 사용하면 전혀 다른 영역이 활성화될 수 있다.

따라서 플레이어의 판단은:

> "어떤 색의 물뿌리개를 지금 사용해야 다음 상태가 유리해지는가?"

가 된다.

---

# 9. 색상 분기 지점

여러 색상의 씨앗이 동시에 발아되는 영역을 주요 퍼즐 포인트로 사용한다.

예:

```text
        🔴
         |
🔵 ──── 🌸 ──── 🟡
         |
        🟢
```

중앙 꽃이 개화하면:

```text
🔴 🔵 🟡 🟢
```

의 여러 색이 동시에 활성화된다.

이후 플레이어는:

```text
🔴 물뿌리개
🔵 물뿌리개
🟡 물뿌리개
🟢 물뿌리개
```

중 무엇을 먼저 실행할지 결정한다.

이것이 기존 Colony Flow의 **블록 투입 순서 퍼즐**에 대응하는 Garden Grow의 핵심 퍼즐 요소다.

# 10. 스테이지 클리어

스테이지의 모든 필수 씨앗이 개화하면 클리어한다.

클리어 순간에는 일반적인 개화보다 강한 연출을 사용한다.

예:

```text
🌸 🌸 🌸 🌸
🌸 🌸 🌸 🌸
🌸 🌸 🌸 🌸
🌸 🌸 🌸 🌸
```

전체 정원이 짧은 시간 동안 **Full Bloom 상태**가 된다.

- 꽃이 동시에 만개
- 파티클
- 화면 효과
- 사운드
- 짧은 카메라 연출

이후 보상 화면으로 이동한다.

# 13. 연쇄 깊이

하나의 선택이 얼마나 깊게 다음 상태를 변화시키는지를 나타내는 지표.

예:

```text
🔴
 ↓
🔵
 ↓
🟡
 ↓
🔴
 ↓
🟢
```

Chain Depth = 5

난이도가 올라갈수록 긴 연쇄를 사용한다.

예상 기준:

### Easy

- Chain Depth: 3~5
- 색상: 2~3개
- 정답: 다수

### Normal

- Chain Depth: 5~10
- 색상: 3~4개
- 정답: 2~5개

### Hard

- Chain Depth: 10~15+
- 색상: 4~5개
- 정답: 1~2개

### Expert

- Chain Depth: 15+
- 색상: 5개 이상
- 정답: 1개
- 초기 선택의 중요도가 높음

# 14. 레벨 생성 방식

단순 랜덤 맵 생성보다는 **역생성(Reverse Generation)**을 사용한다.

## 일반적인 랜덤 생성

```text
랜덤 맵
 ↓
Solver
 ↓
클리어 가능?
```

보다,

## 제안 방식

```text
원하는 개화 연쇄 생성
        ↓
꽃 위치 생성
        ↓
씨앗 위치 생성
        ↓
색상 배치
        ↓
물뿌리개 생성
        ↓
실제 게임 규칙으로 Solver 실행
        ↓
통과한 레벨만 저장
```

방식이 적합하다.

# 15. Level Solver

게임 규칙을 그대로 실행하는 Solver를 별도로 만든다.

Solver는 단순히 "클리어 가능/불가능"만 판단하지 않는다.

다음 정보를 측정한다.

### Solution Count

클리어 가능한 물뿌리개 순서의 개수.

```text
1개 → 어려움
5개 이상 → 쉬움
```

### Chain Depth

필요한 연쇄 깊이.

### Branching Factor

각 상태에서 선택 가능한 물뿌리개의 수.

### Dead End

잘못된 선택 이후 더 이상 클리어할 수 없는 상태.

### Future Water Compatibility

남은 물뿌리개와 현재 발아 꽃의 색상 호환 정도.

### Color Diversity

동시에 활성화되어 있는 색상의 수.

# 16. 상태 탐색

게임 상태를 다음과 같이 정의한다.

```text
GameState
 ├─ Grid
 │   ├─ Seed
 │   ├─ Sprout
 │   └─ Bloom
 │
 ├─ WaterCans
 │   ├─ Color
 │   └─ RemainingCount
 │
 └─ ActiveFlowers
```

플레이어가 물뿌리개를 선택하면 새로운 상태가 만들어진다.

```text
S0
├── 🔴 → S1
├── 🔵 → S2
└── 🟡 → S3
```

각 물뿌리개 내부의 연쇄는 자동으로 실행되므로, Solver가 탐색해야 하는 주요 선택지는 **물뿌리개 사용 순서**다.

DFS/BFS 기반 탐색을 사용할 수 있다.

# 17. 아이템 시스템

아이템은 퍼즐을 자동으로 해결하는 것이 아니라 **막힌 상태에서 퍼즐 상태를 조작하는 역할**을 한다.

기본 철학:

> "정답을 대신 찾아주는 아이템"이 아니라
> "플레이어가 다시 의미 있는 선택을 할 수 있게 만드는 아이템"

# 18. 기본 아이템

## 18.1 물뿌리개 Shuffle

현재 물뿌리개 목록의 순서를 섞는다.

예:

```text
기존
🔴 🔵 🟡 🔴

↓

Shuffle

🟡 🔴 🔴 🔵
```

단, 현재 기획에서 물뿌리개의 사용 순서가 플레이어가 직접 선택하는 구조라면 우선순위가 낮아질 수 있다.

따라서 실제 구현 전 제거 가능.

# 19. 물뿌리개 횟수 추가

현재 물뿌리개의 횟수를 +1한다.

```text
🔴 × 2
    ↓
🔴 × 3
```

효과가 직관적이며 밸런싱하기 쉽다.

---

# 20. 무지개 물뿌리개

색상에 관계없이 발아 꽃에 사용할 수 있는 특수 물뿌리개.

```text
🌈 × 1
```

- 현재 발아 상태의 어떤 색에도 사용 가능
- 자동 타겟팅 규칙은 동일
- 강력한 구제 아이템

게임 초반보다는 중후반에 적합하다.

---

# 21. 대용량 물뿌리개

동일 색상 물뿌리개의 사용 횟수가 많다.

예:

```text
일반
🔴 × 2

대용량
🔴 × 5
```

아이템 자체의 규칙은 단순하지만 레벨 난이도와 강하게 연동된다.

---

# 22. 물뿌리개 저장 아이템

하나의 물뿌리개를 일시적으로 보관하여 현재 선택지에서 제외한다.

예:

```text
현재
🔴 🔵 🟡

저장
🔵

현재 선택 가능
🔴 🟡
```

중후반 전략 아이템 후보.

단, 기본 게임의 조작 복잡도가 증가하므로 MVP 이후 검토한다.

---

# 23. 성장 촉진 아이템

발아 상태의 꽃을 즉시 개화시키는 아이템.

예:

```text
🌿
 ↓
🌸
```

강력한 아이템이므로 사용 횟수를 제한한다.

다만 이 아이템은 게임의 핵심 퍼즐을 직접 해결할 가능성이 있으므로 초기 버전에서는 제외하고 플레이 테스트 후 추가하는 것을 권장한다.

# 25. 가챠 시스템

## 25.1 가챠의 목적

가챠는 게임 플레이에 영향을 주는 능력치가 아니라 **꽃 스킨 수집 콘텐츠**로 사용한다.

따라서 Pay-to-Win 요소를 제거한다.

# 26. 꽃 스킨

플레이어는 다양한 꽃의 외형을 수집할 수 있다.

예:

```text
기본 꽃
🌸

장미
🌹

튤립
🌷

해바라기
🌻

벚꽃
🌸
```

단, 스킨에 따른 게임 능력치 차이는 없다.

모든 꽃 스킨은 동일한 게임 규칙을 사용한다.

# 27. 스킨 차별화 요소

스킨별로 다음 요소를 변경할 수 있다.

- 꽃 모양

- 파티클
- 꽃가루 효과
- 사운드

> 물뿌리개 사용 횟수

등 게임 플레이 능력은 동일하다.

# 28. 가챠 재화

가챠는 **골드**로만 진행한다.

현금 → 가챠 직접 구매 방식은 사용하지 않는다.

구조:

```text
현금
 ↓
골드 구매
 ↓
골드
 ↓
가챠
 ↓
꽃 조각
```

---

# 29. 꽃 조각

각 꽃 스킨은 여러 개의 조각으로 구성된다.

예:

```text
🌹 장미

[■■□□□]
3 / 5
```

필요한 모든 조각을 획득하면 해당 꽃 스킨을 해금한다.

---

# 30. 중복 획득

이미 가지고 있는 꽃 조각을 다시 획득할 수 있다.

중복 조각은 자동으로 골드로 변환한다.

```text
중복 조각
 ↓
골드 환급
```

이를 통해 가챠의 중복 결과가 완전히 무의미해지는 것을 방지한다.

---

# 31. 가챠 확률

꽃의 등급 또는 스테이지 난이도에 따라 조각 획득 확률과 획득 수량을 조정할 수 있다.

예:

```text
일반 꽃
조각 획득 확률 높음

희귀 꽃
조각 획득 확률 낮음

특수 꽃
낮은 확률 + 다량 조각 필요
```

정확한 확률은 경제 시뮬레이션 이후 결정한다.

---

# 32. 상점

상점에는 최대한 단순한 구조를 유지한다.

플레이어에게 명확하게 노출되는 상품은 2종으로 제한한다.

### 1. 광고 제거

광고를 영구적으로 제거하는 상품.

### 2. 골드 구매

가챠에 사용하는 골드를 구매한다.

```text
SHOP

[ 광고 제거 ]

[ 골드 구매 ]
```

불필요한 상품 종류를 늘리지 않는다.

---

# 33. 광고 BM

핵심 게임 플레이와 광고 노출을 자연스럽게 결합한다.

게임은:

```text
플레이어 선택
 ↓
자동 물주기
 ↓
개화 애니메이션
 ↓
주변 발아
 ↓
다음 선택
```

이라는 자동 처리 구간을 갖는다.

이 구간에 하단 배너 광고를 노출한다.

중요한 원칙:

> 광고 노출을 위해 인위적으로 게임 속도를 늦추지 않는다.

개화 애니메이션과 결과 확인 시간 자체가 자연스러운 광고 노출 구간이 되도록 설계한다.

---

# 34. 광고 확장 가능성

향후 Rewarded Ad를 추가할 수 있다.

예:

- 실패 후 물뿌리개 +1
- 힌트 1회
- 무지개 물뿌리개 1개
- 추가 골드
- 한 번의 행동 Undo

단, MVP에서는 광고 제거 + 배너 정도로 시작해도 된다.

# 35. 경제 시스템

기본 경제 구조:

```text
게임 플레이
 ↓
골드 획득
 ↓
가챠
 ↓
꽃 조각
 ↓
꽃 스킨 해금
```

그리고:

```text

 ↓
골드
 ↓
가챠
 ↓
꽃 조각
```

을 추가한다.

중복 조각은:

```text
중복 조각
 ↓
골드
```

로 환급한다.

# 36. Pay-to-Win 방지

꽃 스킨은 순수한 Cosmetic 콘텐츠다.

스킨에 능력치를 부여하지 않는다.

따라서:

```text
고가 꽃
≠
강한 꽃
```

이다.

게임 플레이의 실력과 레벨 해결 능력은 모든 플레이어에게 동일하다.

# 38. 기술 설계의 핵심 원칙

게임 로직은 애니메이션과 분리한다.

```text
Player Input
    ↓
Game State
    ↓
Rule Processing
    ↓
State Transition
    ↓
Animation
```

예를 들어:

```text
WaterCanUsed
    ↓
FindTarget
    ↓
WaterFlower
    ↓
BloomFlower
    ↓
ActivateNeighbors
    ↓
DecreaseWaterCount
    ↓
FindNextTarget
```

애니메이션은 이 결과를 표현하는 역할만 담당한다.

이렇게 해야 Level Solver가 실제 게임과 동일한 규칙을 사용할 수 있다.

# 39. Deterministic Rule

특히 자동 타겟팅은 반드시 결정론적으로 구현한다.

```text
DOWN
LEFT
RIGHT
UP
```

순서를 고정한다.

동일한 게임 상태에서 동일한 물뿌리개를 사용하면 항상 동일한 결과가 나와야 한다.

이것은:

- 레벨 Solver
- 리플레이
- 디버깅
- 버그 재현
- 레벨 검증
- 향후 서버 검증

에 중요하다.

# 41. 게임의 핵심 차별점

Garden Grow의 핵심은 단순한 "꽃 퍼즐"이 아니다.

게임의 핵심은:

> **색상별 물뿌리개의 사용 순서와 제한된 횟수를 이용해 개화 연쇄를 제어하는 것**

이다.

따라서 게임의 핵심 경험은:

```text
"어떤 꽃에 물을 줄까?"
```

보다는

```text
"어떤 물뿌리개를 먼저 실행해야
다음 연쇄가 원하는 방향으로 진행될까?"
```

에 가깝다.

# 42. 디자인 원칙

### 원칙 1
**플레이어의 선택은 단순하게, 결과는 깊게.**

플레이어는 물뿌리개를 선택하지만 이후 물주기는 자동으로 처리한다.

### 원칙 2
**자동 실행은 결정론적으로.**

같은 상태 + 같은 물뿌리개 = 같은 결과.

### 원칙 3
**아이템은 정답을 제공하지 않는다.**

막힌 퍼즐을 다시 풀 수 있는 상태로 만들어주는 역할을 한다.

### 원칙 4
**스킨은 Pay-to-Win이 아니다.**

꽃 스킨은 외형과 연출만 변경한다.

### 원칙 5
**레벨은 역생성한다.**

원하는 개화 연쇄를 먼저 설계하고 실제 게임 규칙으로 검증한다.

### 원칙 6
**난이도는 정량화한다.**

Chain Depth, Solution Count, Branching, Dead End 등의 지표를 사용한다.

# 43. 현재 미확정 사항

다음 항목은 프로토타입에서 반드시 테스트해야 한다.

1. 개화 영향 범위
   - 4방향

2. 이미 발아한 꽃이 다시 주변 꽃의 개화로 영향을 받을 경우의 처리

4. 동일한 색상의 발아 꽃이 여러 개 존재할 때 정확한 타겟 선택 기준

5. 물뿌리개 횟수가 남았지만 대상 꽃이 없는 경우의 처리

6. 모든 물뿌리개가 소진됐지만 아직 꽃이 남은 경우의 실패 처리

7. 물뿌리개 사용 중 애니메이션을 스킵할 수 있는지

8. Undo 제공 여부

9. 힌트 시스템

10. 장애물 시스템

11. 골드 획득량 및 가챠 비용

# 45. 최종 핵심 정의

**Garden Grow는 제한된 횟수의 색상별 물뿌리개를 올바른 순서로 사용하여 꽃의 개화 연쇄를 제어하고, 모든 씨앗을 꽃으로 성장시키는 캐주얼 퍼즐 게임이다.**

핵심 퍼즐은:

> **물뿌리개 선택 → 자동 물주기 → 개화 → 주변 발아 → 새로운 상태 생성**

이며,

핵심 전략은:

> **"지금 어떤 색을 실행해야 미래의 선택지가 유리해지는가?"**

이다.

이를 통해 Colony Flow와 유사한 **순서 선택에 따른 연쇄 퍼즐의 재미**를 유지하면서도, Garden Grow만의 **성장/개화/확장이라는 게임 경험**을 만든다.
