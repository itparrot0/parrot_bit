# 경제 시뮬레이션 — Deep Grove 첫 테마 (2026-11-05)

> `apps/deep_grove/tool/economy_sim.dart`. 앱과 **같은 규칙 코드**(BoardModel·Economy) 위에서
> 자동 플레이어가 판을 끝까지 진행한다. 수치(`lib/domain/theme.dart`)를 직접 플레이 전에 점검하고,
> PRD §10 열린 질문(보드 막힘·생성기 탭 제한·경제 수치)에 답하기 위해 만들었다.
>
> ```sh
> cd apps/deep_grove
> dart run tool/economy_sim.dart --runs 20
> ```

## 방법

- **자동 플레이어**: 확장할 수 있으면 가장 싼 칸(창고가 작으면 창고) → 수확 → 머지(높은 레벨 먼저,
  산출원이 될 머지는 자기 지대 칸에서) → 산출원을 자기 지대로 옮기기 → 필요한 자원 쪽 생성기 탭 →
  할 게 없으면 기다림. "꽤 잘하는 사람" 수준이라 **시간은 하한으로 읽는다.**
- **조작 시간**: 탭 0.6초, 드래그 1.2초, 확장 시트 +0.3초.
- **플레이 방식**: 계속 플레이 / 5분 플레이 · 60분 쉼(쉬는 동안 방치 산출, 돌아와 복귀 보상).
- **막힘 판정**: 플레이 중 12시간 동안 확장이 없으면 막힌 것으로 본다.
- 한계: 판마다 다른 건 생성 위치뿐이라 판 사이 차이가 거의 없다. 사람마다의 차이(실수, 순서)는
  재지 못한다. 광고·상품은 끈 상태다.

## 찾은 버그 — 고침

**창고가 거의 차면 산출이 영구히 멈췄다.** 남은 빈 공간이 산출원 여럿에 1 미만씩 흩어져 쌓이고
(예: 산출원 29개에 빈 공간 6), 어느 산출원도 1이 되지 않아 탭으로 거둘 수 없었다. 쌓인 합계는 이미
빈 공간과 같아 더 쌓이지 않고, 복귀 보상도 새로 익은 양이 0이라 뜨지 않는다. 산출원이 많아지면
실제 플레이에서도 생기는 정지였다.

→ `BoardModel.advance`가 빈 공간을 **다 익은 양(정수)** 기준으로 나누게 고쳤다. 산출원은 다음 한
단위가 빈 공간을 넘으면 그 정수에서 멈춘다. 빈 공간만큼은 언제나 거둘 수 있다 (회귀 테스트 있음).

## 결론

### 1. 지금 수치는 너무 빠르다 (PRD §10-2·3)

쉬지 않고 하면 **첫 테마 전체가 18분**, 하루 몇 번 5분씩 해도 반나절이다. 원인은 **생성기를 무한으로
누를 수 있다는 것**이다. 거목 하나는 씨앗 16개(조작 약 30초)면 되고 영구히 자원을 내므로, 산출원이
보드 크기만큼 금방 늘어 산출이 기하급수로 커진다. 비용을 5배로 올려도 50분이다 — **빈 칸만으로는
진행 속도가 조절되지 않는다** (§10-2의 답: 아니다).

### 2. 보드 막힘은 실제로 생긴다 (PRD §10-1)

산출을 늦춘 후보에서 20판 모두 같은 함정에 빠졌다:

1. 숲을 목재 산출원(거목)으로 채운다 — 산출원은 없앨 수 없다.
2. 목재만 드는 칸(숲 6, 동굴 4)을 다 연다.
3. 다음 칸은 전부 광석을 요구하는데, 돌을 키울 빈 칸이 없다 (빈 칸 0, 머지할 짝 없음).

목재는 계속 나오지만 **영원히 진행할 수 없다.** 다른 후보는 진행 속도가 맞아 운 좋게 피했을 뿐,
사람이 숲부터 채우면 어떤 수치에서도 같은 함정에 빠질 수 있다. **해소 장치가 필요하다.**

## 정해야 할 것

1. **막힘 해소 장치** (필수). 후보:
   - **판매** — 조각을 보드 밖 판매 칸에 끌어다 놓으면 사라지고 자원을 조금 돌려받는다. 산출원도
     팔 수 있다. 머지 장르에서 흔하고 조작 규칙(드롭 판정)에 칸 하나만 더하면 된다.
   - **보관함** — 산출원을 보드 밖 보관함에 넣었다 뺄 수 있다. 잃는 게 없지만 UI가 하나 더 생긴다.
   - **수치로 막기** — 광석이 필요해지기 전에 열 수 있는 목재 칸을 늘린다. 함정을 늦출 뿐 없애지 못한다.
2. **첫 테마 목표 길이.** 예: "하루 5분 × 4~5번으로 2~3일". PRD에 아직 없다.
3. **속도 조절 손잡이.** 표에서 보듯 비용만으로는 부족하다:
   - **생성기 에너지** — 가장 확실하다. 다만 PRD §10-2에서 "v1은 넣지 않는 쪽"으로 두었고,
     넣으면 수익 모델(에너지 충전 광고·상품)과 다시 엮인다.
   - **생성기 쿨다운**(탭 사이 대기) — 에너지보다 단순하지만 손맛이 줄어든다.
   - **산출을 늦추고 비용을 올리기** — 1번 해소 장치가 있어야 가능하다 (지금은 막힘 100%).

목표 길이(2)와 손잡이(3)가 정해지면, 시뮬레이터의 후보 목록에 넣어 목표에 맞는 수치를 찾는다.
