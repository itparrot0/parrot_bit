## 2. 규칙 엔진 (`lib/domain/engine.dart`)

### 2.1 데이터
- **레벨**: 너비·높이, 팔레트(HEX), 칸별 색(빈 칸 = -1), 시작 발아 칸 목록, 대기열 줄들(줄마다 `물방울{색, 양}` 목록),
  활성 슬롯 수(4), 옵션 `realtime`(기본 true)·`visible`(기본 3, 표시 전용), 메타(난이도 지표·그림 이름).
- **상태**: 칸 상태(씨앗 0 / 발아 1 / 개화 2 / 빈 칸 -1), 칸별 발아 순번(`seq`)·발아한 틱(`bornTick`),
  색별 발아 칸 수, 남은(미개화) 칸 수, 남은 대기열, 슬롯 4칸, 진행 상태(playing / cleared / failed).
- 시작: 모든 칸 씨앗 → `starts` 순서대로 발아(순번 0, 1, …).

### 2.2 탭 (`deploy`)
- 줄 하나의 **맨 앞 물방울**을 **첫 빈 슬롯**으로 옮긴다. 그 색 발아 칸이 없어도 옮겨진다(슬롯에서 기다림).
- 탭할 수 있는 조건(`legalActions`): 빈 슬롯이 있고, 웨이브가 진행 중이면 `realtime`이 true여야 한다.
  튜토리얼 1·2는 `realtime: false` → 웨이브가 멈춘 뒤에만 탭.
- **set (2026-11-05)**: 서로 다른 줄의 물방울 2~3개를 묶은 것(물방울의 `set` 번호가 같음). **묶인 물방울이 모두 줄 맨 앞일 때만** 탭할 수 있고(`frontGroup`·`canDeploy`),
  탭하면 **set 전체가 빈 슬롯으로 한꺼번에**(줄 번호 순) 들어간다(`deployGroup`). 빈 슬롯이 set 크기보다 적으면 넣을 수 없다.
  행동 목록에는 set 하나당 가장 작은 줄 번호 하나로만 나온다.

### 2.3 틱 (`tick`) — 한 틱에 "한 링"
슬롯 0→3 순서로, 각 물방울(양 > 0, 같은 색 발아 칸 > 0)에 대해:
1. **링** = 같은 색 발아 칸 중 **이번 틱 전에 발아한 칸** 전부, 발아 순번 순.
2. 앞에서부터 **남은 양만큼** 개화. 양이 부족하면 링의 앞부분만 핀다.
3. 핀 칸은 8방향 이웃 씨앗을 **색과 상관없이** 발아시킨다. 방향 순서: 남동 → 남 → 남서 → 서 → 북서 → 북 → 북동 → 동.
   새로 발아한 칸은 다음 틱 링부터 들어간다.
4. 양이 0이 되면 슬롯이 비워진다. 남으면 다음 틱에 링을 다시 계산한다.

### 2.4 판정 (`judge`, 상태가 바뀔 때마다)
- 남은 칸 0 → **완성(cleared)**.
- 슬롯의 물방울 중 하나라도 퍼질 수 있으면 → 진행 중(웨이브).
- 아무것도 못 퍼지는 **안정 상태**에서 **넣을 수 있는 물방울이 하나도 없으면** → **실패(failed)**: 슬롯이 모두 찼거나, 대기열이 비었거나,
  set 이 막혔을 때(짝이 맨 앞에 못 오거나 빈 슬롯이 모자람). set 이 없는 레벨은 예전 규칙(슬롯이 찼거나 대기열이 빔)과 같다.
- 물방울 총량 = 칠할 칸 수(생성기·검증기가 보장)라 물이 남거나 모자라서 지는 일은 없다. 지는 길은 "슬롯 막힘"뿐.

### 2.5 솔버 (`solver.dart`)
- 깊이 우선 탐색 + 실패 상태 메모(상태 키 = 칸 상태·발아 순서·"막 발아함" 표시·줄 길이·슬롯 내용).
- 시도 순서: ①지금 퍼질 수 있는 물방울 넣기 → ②기다리기(틱) → ③못 쓰는 물방울 넣기. 노드 한도(기본 20만, 힌트 3만).
- **무작위 플레이어**(난이도 측정용): 퍼질 수 있는 넣기 3 : 기다리기 2 : 못 쓰는 넣기 1의 가중치로 고른다.
- TS 버전과 결과가 같다(`test/domain/ts_parity_test.dart`: 120레벨 해법·노드 수, 생성 레벨 바이트 단위).

## 3. 한 판의 진행 (`lib/game/game_controller.dart`)

- **틱 타이머**: 매 프레임 경과 시간을 누적해 **기본 450ms마다 1틱**, **x2를 켜면 300ms마다**(`items.dart`의 `baseTickMs`·`x2TickMs`). 프레임당 최대 4틱.
  웨이브가 없으면 누적을 0으로. 일시정지 중·끝난 뒤에는 멈춘다.
- **탭 결과**: 성공(슬롯 번호), `full`(슬롯 4칸 다 참 → 슬롯 흔들림 + 거절음), `wait`(realtime=false인데 웨이브 중 → 거절음),
  `empty`(빈 줄), `over`(끝난 판). 탭 직후 누적 시간을 0으로 돌려, 넣은 물방울은 **다음 틱부터** 함께 퍼진다.
- **웨이브가 멈추면**(진행 중 → 안정) "idle" 이벤트: 개화음 높이 초기화, 대기열 맨 앞 물방울들이 튄다(이제 넣으라는 신호).
- **재시작**: 처음 상태로. 되돌리기 기능은 없다(2026-11-04 삭제).
- 힌트 기능은 없다(2026-11-05 삭제).
- **아이템 호출**: 슬롯 추가(`addSlotItem`), 섞기(`shuffleItem`), 즉시 개화(`bloomItem`) — 규칙은 엔진 함수(`addSlot`·`shuffleLanes`·`forceBloom`). 자세한 동작은 §5.4.

## 4. 화면과 흐름

모든 화면은 **논리 해상도 1080×2340**(9:19.5)으로 그려 화면에 비율 유지로 맞춘다. 남는 위·아래(좌·우)는 배경색,
노치·내비게이션 바는 논리 좌표로 환산한 여백만큼 비켜 그린다. 글자 크기는 기기 글꼴 배율을 따르지 않는다.

```
홈 ──시작──▶ 게임 ──완성──▶ [홈] / [다음 스테이지 → 게임]   (떠날 때 전면 광고 1회)
 │                └─실패──▶ [다시 하기] / [홈]              (광고 없음)
 ├─상점──▶ 스킨 모음·광고 제거 ──▶ 스킨 뽑기
 └─스킨 뽑기──▶ 가챠 머신
```

### 4.1 홈 (`screens/home_screen.dart`)
- 왼쪽 위 **햇빛 배지**(해 + 개수 + 다음 회복까지 남은 시간 / "가득", 누르면 햇빛 패널 §5.6), 오른쪽 위 **골드 잔액**, 제목·부제, 가운데 그림(가장 최근에 완성한 그림, 없으면 1스테이지 그림의 회색 실루엣)이 위아래로 천천히 뜬다.
- 버튼: **[스테이지 N 시작]**(초록, 큰 버튼) · **[상점]** · **[스킨 뽑기]**. 스테이지 맵·정원은 없다(지난 스테이지는 다시 하지 않음).
- 햇빛이 0개면 [스테이지 N 시작]을 눌러도 시작하지 않고 햇빛 패널("햇빛이 없어요")을 띄운다.
- N = 다음 스테이지 = 저장의 `unlocked`(완성한 스테이지는 건너뜀). 마지막 스테이지까지 완성하면 시작 버튼 대신 "모든 스테이지 완성!".
- 뒤로 가기: "게임을 종료할까요?" [종료]/[취소].

### 4.2 게임 화면 (`screens/game_screen.dart`, `game/*`)
**배치**(위→아래, `game_layout.dart`):
- 상단: 왼쪽 **[x2 남은 시간]**(§5.5, 예: `x2 9:58`), 가운데 "스테이지 N"과 그림 이름, 오른쪽 [Ⅱ](일시정지). 뒤로(‹) 버튼은 없다 — 홈은 일시정지 메뉴에서.
- 보드: 위에서 210 아래부터, 가로 최대 1040·세로 최대 1000(화면 길이에 따라 500~1000) 안에 칸 크기를 정수로 맞춤.
- 활성 슬롯 4칸: 보드 바로 아래 한 줄(반지름 78, 간격 210). 슬롯 추가 아이템으로 5~6칸이 되면 간격·크기가 줄어 한 줄에 맞는다. **3칸 이상 차면 빨간 경고색.**
- 대기열: 줄마다 세로 기둥(3~4줄). 맨 위가 탭할 물방울(큰 동그라미), 그 아래 다음 2개가 작게. **그 뒤로 몇 개가 남았는지(+N)는 보여 주지 않는다**(2026-11-05) — 줄이 언제 끝날지, 다음 2개 뒤에 어떤 색이 있는지 알 수 없다. **다 쓴 줄은 영역째 사라지고 남은 줄이 가운데로 미끄러져 모인다**(약 0.25초, 줄 폭·물방울 크기는 그대로).
  **"?" 물방울**(§8): 다음 2개 자리에서는 회색 물방울에 "?"만 보이고(색·크기 모두 숨김), 맨 위(탭할 자리)에 올라오면 드러난다.
  길게 눌러 색 미리보기는 맨 위 물방울만 되므로 "?" 물방울에는 미리보기가 없다.
  **set 물방울**: 둘레에 set 색 고리(보라·청록·주황을 set 번호 순으로) + 오른쪽 위 고리 배지. 맨 위에 왔지만 짝이 아직이면 흐리게(50%),
  모두 맨 위에 오면 그 줄들 맨 위를 set 색 띠로 잇는다. 짝이 아직인데 누르면 "묶인 물방울이 모두 맨 위에 와야 해요"(줄이 통 튐),
  빈 슬롯이 모자라면 슬롯이 흔들리고 "빈 슬롯이 N칸 필요해요". 넣으면 모두 각자 줄에서 슬롯으로 날아간다.
- 하단: **아이템 칸 3개**(슬롯 추가 · 섞기 · 즉시 개화, §5.4) — 아이콘·이름·남은 개수. 잠긴 칸은 자물쇠와 "N스테이지". 재시작은 일시정지 메뉴에만 있다.
- **맨 아래 배너 광고**(2026-11-04): 게임 캔버스 **밖** 화면 맨 아래 띠. 캔버스(보드·버튼)는 배너를 뺀 높이에 맞춰 조금 작아지고,
  버튼과 배너 사이는 8dp 띄운다(잘못 누르기 방지). 시스템 내비게이션 바 위에 놓인다. 안내·일시정지·완성·실패 패널이 떠도 배너는 그대로.
  광고 제거 구매자는 배너가 없고, 게임 중 설정에서 사면 바로 사라진다. 홈·상점·뽑기 화면에는 배너가 없다.

**입력** — 대기열 맨 위 동그라미(반지름 = 물방울+24)를:
- **누르고 있으면** 보드에서 그 색의 **지금 발아한 칸만** 또렷하게 + 빛나는 테두리(씨앗·이미 핀 칸·다른 색은 22% 불투명도). 그 색 발아 칸이 없으면 보드 전체가 흐려져 "지금 넣어도 퍼질 곳이 없다"가 보인다(2026-11-05).
- **동그라미 안에서 떼면** 넣기, **누른 채 밖으로 벗어나면 취소**(넣지 않음).

**시작 안내**(차례로 하나씩, 안내 중에는 게임이 멈춤):
1. 난이도 경고: hard / superHard / megaHard 스테이지는 **Hard / Super Hard / Mega Hard** 배지 + "어려운 스테이지예요" + [도전하기].
2. 튜토리얼: 1 웨이브 / 2 여러 줄 / 3 웨이브 중 넣기 / 4 기다리는 물방울 / 5 슬롯이 막히면 패배.
3. 1스테이지: 길게 눌러 색 확인 안내. **비슷한 색(ΔE < 25)이 처음 나오는 스테이지(현재 14)**: 두 색 견본과 함께 안내.
4. **"?" 물방울이 처음 나오는 스테이지(현재 100)**: "?" 물방울 안내(회색 "?" 그림). **set 이 처음 나오는 스테이지(현재 150)**: set 안내(띠로 이어진 두 물방울 그림).
5. **아이템 해금 스테이지(8·12·17)**: 아이템 안내창("○○ 3개를 받았어요!" + 설명 + [써 보기]) → 그 아이템을 한 번 쓸 때까지 대기열이 잠긴다(§5.4).

**일시정지 메뉴**: [계속하기] [재시작] [설정] [홈]. 앱이 백그라운드로 가면 자동으로 일시정지 메뉴를 띄운다.

**뒤로 가기**(시스템): 플레이 중 → 일시정지 메뉴 / 일시정지·안내 → 닫고 계속 / 설정 → 일시정지로 / 완성 화면 → (광고 후) 홈 / 실패 → 홈.

**완성**:
1. 완성음·진동, 보드가 대각선 순서로 반짝(칸마다 35ms 시차, 520ms), 꽃잎 40장(1.4초).
2. 골드를 굴려(§5.1) 저장에 기록, 다음 스테이지를 연다.
3. 1.8초 뒤(빠른 연출 0.7초) 완성 패널: **FULL BLOOM**, 완성한 그림, "완성!"과 이름, **동전 + "+N"(0부터 올라감)·잔액**, 버튼 **[홈] [다음 스테이지]**(마지막 스테이지는 [홈]만). 골드를 받았으면 동전 소리.
4. 어느 버튼이든 누르면 **전면 광고 1회**(광고 제거 구매자는 건너뜀) 후 이동.

**실패**: 실패음·강한 진동, 슬롯이 흔들리고 슬롯 물방울이 회색, 보드가 어두워짐(55%). 0.8초 뒤 "슬롯이 막혔어요" + [다시 하기] [홈]. 광고 없음.

**연출 시간**(`game_fx.dart`, 표의 ms 는 틱 300ms(x2) 기준 — 기본 450ms 에서는 시차 상한이 그만큼 넉넉해진다) — 각 틱의 연출은 다음 틱 전(틱의 80%) 안에 끝나게 맞춘다. 입력은 막지 않는다.
| 연출 | 동작 |
|---|---|
| 넣기 | 줄 맨 앞 → 슬롯으로 곡선 비행 380ms (위로 160 솟았다 내려옴), 탭 소리 |
| 개화 | 링 안에서 발아 순서대로 시차 `min(40ms, 240ms/칸 수)`, 70ms 뒤 개화 시트(`assets/anim/bloom_<스킨>.png`, 지금 8프레임 × 32ms)를 칸마다 재생. 슬롯에서 칸까지 물줄기 320ms, 슬롯이 살짝 커졌다 돌아옴 220ms. 개화음은 틱마다 반음씩 높아짐(최대 2옥타브) + 가벼운 진동(90ms에 1번까지) |
| 발아 | 개화 후 80ms부터 `min(24ms, 240ms/칸 수)` 시차, 60ms 뒤 발아 시트(`assets/anim/sprout.png`, 8프레임 × 32ms)를 칸마다 재생. 시트를 불러오기 전에는 코드 그리기(싹 세로로 돋음·꽃 0.6→1.15→1, 260ms) |
| 웨이브 멈춤 | 맨 앞 물방울들이 0.9초 동안 튐 |
| 빠른 연출(설정) | 시차·물줄기·꽃잎 없음, 완성 패널 0.7초 |

**보드 칸 모양**: 씨앗(어두운 바탕에 작은 점), 발아(조금 밝은 바탕에 흰 싹), 개화(그림 색 바탕에 **장착한 스킨의 꽃 모양**).
색은 늘 그림 색 그대로라 스킨이 퍼즐에 영향을 주지 않는다.

### 4.5 스킨 뽑기 (`screens/gacha_screen.dart`)
- 화면: 골드 잔액, 가챠 머신(유리 돔 안 캡슐 16개, 빨간 몸통, 손잡이, 나오는 구멍), [뽑기 · 100 골드], **[광고 보고 무료 뽑기 · 하루 1번]**(2026-11-05), [확률 보기].
- **무료 뽑기**: 보상형 광고(§7)를 끝까지 보면 골드 없이 한 번 뽑는다(같은 연출). **하루 1번, 햇빛 광고 충전과 같은 아침 6시(현지 시각) 초기화**. 쓴 뒤에는 버튼이 꺼지고 "무료 뽑기는 아침 6시에 다시". 광고를 끝까지 보지 않으면 "광고를 끝까지 봐야 뽑을 수 있어요"만 뜨고 기회는 남는다. 모든 스킨을 해금하면 버튼이 없다.
- **뽑기를 누르면**: 규칙(§5.2)대로 결과를 정하고 **바로 저장**한 뒤 연출(2.6초)을 튼다. 연출 중에 앱이 꺼져도 결과는 남는다.
  | 구간 | 연출 |
  |---|---|
  | 0 ~ 27% | 손잡이 한 바퀴, 돔 안 캡슐들이 흔들림 |
  | 27 ~ 52% | 뽑힌 스킨 색 캡슐이 구멍에서 나와 받침으로 떨어져 튐 |
  | 52 ~ 64% | 캡슐이 들썩임 |
  | 64 ~ 82% | 캡슐 윗뚜껑이 열리며 금빛과 빛줄기 |
  | 끝 | 결과 패널 |
- 머신을 탭하면 건너뛴다. 연출 중에는 뒤로 가기·뽑기 버튼이 막힌다. 연출 중 골드 잔액은 반환 골드를 뺀 값으로 보이다가 결과에서 더해진다.
- 결과 패널: **새 조각!**(카드에서 새 조각이 금테로 깜빡임) / **이미 가진 조각**("+10 골드 돌려받음") / **스킨 해금!**(카드가 튀어 오름, [바로 장착] [확인]).
- 골드 부족: "골드가 부족해요"(빨간 글자), 아무것도 바뀌지 않음. 모든 스킨 해금: 버튼이 "모든 스킨을 해금했어요!"로 잠김.
- **확률 보기**: 규칙 설명 + 스킨마다 지금 확률(소수 둘째 자리 %)과 "조각 하나 x%". 해금한 스킨은 "해금됨 · 제외".
  같은 함수(`gachaOdds`)를 읽으므로 표시와 실제가 어긋나지 않는다.
- 연출은 이 화면에서만 돌고, 뽑지 않을 때는 다시 그리지 않는다 → 게임 성능과 무관.

### 5.1 골드 (`gold.dart`)

### 5.2 스킨 뽑기 (`gacha.dart`)
| 항목 | 값 | 조절 위치 |
|---|---|---|
| 1회 비용 | 100 골드 | `GachaConfig.pullCost` |
| 중복 반환 | 비용의 10% (내림) = 10 골드. 무료 뽑기(광고)도 같은 10 골드 | `GachaConfig.refundRate` |
| 후보 | 해금하지 않은 스킨의 **모든 조각**(이미 가진 조각 포함) | — |
| 확률 | 조각마다 같음: 조각 1/후보 수, 스킨 = 조각 수/후보 수 | — |

- 처음엔 5스킨 × 4조각 = 20조각 → 스킨마다 20%, 조각마다 5%.
- 이미 가진 조각이 나오면 중복 → 10 골드 반환. 새 조각으로 4조각이 다 모이면 **해금**, 그 뒤로 그 스킨의 조각은 후보에서 빠진다
  (예: 한 스킨 해금 후 16조각 → 남은 스킨마다 25%).
- 순서: 골드 차감 → 조각 추가(중복이면 반환) → 저장. 뽑을 수 없으면(골드 < 100, 후보 없음) 아무것도 바뀌지 않는다.

### 5.3 꽃 스킨 (`skins.dart`, `ui/skin_art.dart`)

- 해금된 스킨만 장착할 수 있다. 장착한 스킨이 잠겨 있으면(옛 저장 등) 기본 꽃으로 그린다.
- 모양은 스킨마다 128×128 상자 안의 경로 하나를 **처음 한 번만** 만들어 재사용한다. 개화 칸마다 그리기 1번이라 스킨과 관계없이 그리는 비용이 같다.
- 스킨 추가: `skins.dart` 목록 한 줄 + `skin_art.dart` 모양 하나.

### 5.4 플레이 아이템 (`items.dart`, 2026-11-05)
게임 화면 하단 아이템 칸에 늘 떠 있고, 쓸 때마다 1개씩 줄어든다. 개수가 0이면 "남은 아이템이 없어요".

| 아이템 | 해금 | 동작 |
|---|---|---|
| **슬롯 추가** | 8스테이지 | 이번 판의 활성 슬롯 +1칸 (최대 6칸, 넘으면 "슬롯은 6칸까지예요"). 재시작하면 4칸으로 돌아간다 |
| **섞기** | 12스테이지 | 대기열에 남은 물방울 전부(맨 위 포함)를 **모든 줄에 걸쳐** 무작위로 섞어 다시 나눠 담는다. 줄마다 개수는 그대로. 섞은 배치를 솔버(2만 노드)로 확인해 **완성할 수 있는 배치만** 쓴다(12번 시도, 판정 못 하면 받아들임). 못 찾으면 쓰지 않고 개수도 그대로("지금은 섞을 수 없어요") |
| **즉시 개화** | 17스테이지 | 누르면 **퍼질 곳이 없어 묶인 물방울**(같은 색 발아 칸이 없음)이 든 슬롯에 금빛 고리가 생기고, 그중 하나를 고르면 그 물방울을 다 쓸 때까지 **같은 색의 아직 안 핀 칸을 무작위로** 하나씩 바로 피운다. 핀 칸은 보통 규칙대로 8방향 씨앗을 발아시킨다. 묶인 물방울이 없으면 쓸 수 없다. 고르는 중에 아이템을 다시 누르면 취소 |

- 같은 색끼리 피우므로 "물방울 총량 = 칸 수"가 유지된다(즉시 개화로 판이 깨지지 않는다). 즉시 개화로 마지막 칸이 피면 그대로 완성.
- **해금·튜토리얼**: 튜토리얼 5스테이지 뒤로 3·4·5 스테이지 간격(8 → 12 → 17). 해금 스테이지에 처음 들어오면 **3개 지급** + 안내창.
  [써 보기]를 누르면 그 아이템을 **한 번 쓸 때까지 대기열이 잠기고**("아이템을 눌러 써 보세요", 그 아이템 칸이 금테로 두근거림, 다른 아이템은 흐림)
  쓰면 풀린다 → **2개가 남는다**. 즉시 개화 튜토리얼은 묶인 물방울이 없으면 지금 퍼질 수 없는 맨 앞 물방울을 하나 슬롯에 넣어 준다.
  튜토리얼을 마치면 다시 들어와도 지급·안내가 없다. 쓰기 전에 나가면 다음에 그 스테이지에서 다시 안내한다(지급은 한 번만).
- 아이템을 더 얻는 방법은 아직 없다(§12).

### 5.5 x2 속도 (`items.dart`, 2026-11-05)
- 기본 속도는 느린 속도(틱 450ms). 왼쪽 위 **[x2 남은 시간]** 버튼을 누를 때마다 켜기/끄기, 켜면 틱 300ms. 켜짐은 금색.
- **켜 둔 동안 웨이브가 실제로 진행될 때만** 남은 시간이 준다(일시정지·안내창·완성/실패 패널·웨이브가 멈춘 동안은 줄지 않음). 0이 되면 저절로 꺼지고 "x2 시간을 다 썼어요", 다시 켤 수 없다.
- 처음 주는 시간 **10분**(`x2InitialMs`). 켜짐 상태는 다음 스테이지에도 이어진다. 남은 시간은 5초마다·일시정지·화면을 떠날 때 저장.
- 더 얻는 방법은 아직 없다(§12).

### 5.6 햇빛 = 라이프 (`lives.dart`, `screens/lives_panel.dart`, `ui/sun.dart`, 2026-11-05)
- 최대 **5개**(`maxLives`). 모자라면 **20분마다 1개**(`lifeRegen`)씩 찬다. 앱이 꺼져 있어도 시각으로 계산한다(회복 기준 시각을 저장). 가득일 때 쓰면 그 순간부터 20분, 회복 도중에 더 써도 시계는 그대로.
- **스테이지를 시작할 때 1개를 쓰고, 완성하면 돌려받는다.** 그래서 실패하거나 도중에 그만두면(다시 하기·홈·앱 종료) 1개가 줄어든다. [다시 하기](실패 패널·일시정지 메뉴)도 새 도전이라 1개를 쓴다. 완성 → [다음 스테이지]는 돌려받은 뒤라 언제나 시작할 수 있다.
- 0개면 시작·다시 하기 대신 **햇빛 패널**: 해 5개(찬 것/빈 것), 다음 회복까지 남은 시간(1초마다 갱신), 설명, 버튼 둘, [닫기]. 게임 안에서 열렸으면 닫을 때 원래 패널(실패/일시정지)로 돌아간다.
  - **[100 골드로 가득 채우기]**(`refillGoldCost`): 골드가 모자라면 "골드가 모자라요"만.
  - **[광고 보고 가득 채우기]**: 보상형 광고(§7)를 끝까지 보면 가득. **하루 1번, 아침 6시(현지 시각)에 초기화**(`adResetHour`) — 6시 전은 전날로 친다. 끝까지 보지 않으면 채워지지 않고 기회도 남는다.
  - 가득이면 두 버튼 모두 꺼진다.
- 실패 패널에 "남은 햇빛 N개". 기기 시계를 뒤로 돌리면 회복 기준을 지금으로 당긴다(몰아 받기·회복 멈춤 방지).

### 5.7 골드 구매 (`gold_packs.dart`, `platform/billing.dart`, 2026-11-05)
- 소모성 인앱 상품 4개: **`gold_500` 500** · **`gold_1100` 1,100**(1,000 + 10%) · **`gold_3000` 3,000**(2,500 + 20%) · **`gold_6500` 6,500**(5,000 + 30%). 참고 가격 1,200 · 2,400 · 5,900 · 11,000원(스토어에서 정함).
- 결제 결과는 앱이 켜져 있는 동안 늘 듣는다(`Billing.start`, 앱 시작 때). 완료된 골드 결제는 **먼저 골드를 지급·저장한 뒤** 스토어에 완료를 알린다(Android는 직접 소모 consume, iOS는 completePurchase). 지급 전에 앱이 꺼지면 다음 실행 때 다시 와서 지급된다. 대기 결제(편의점·계좌 등)도 끝나는 대로 지급.
- 같은 결제가 두 번 와도 **주문 id로 한 번만** 지급(저장의 `orders`, 최근 100개).
- Android 플러그인의 autoConsume은 쓰지 않는다: 지급 전에 소모하고, 앱을 다시 켠 뒤 도착한 결제는 소모하지 않아 그 상품을 다시 살 수 없게 되기 때문.

## 6. 저장 (`lib/save/save_store.dart`)

- 기기 로컬(shared_preferences) 키 `bloomwave.save`에 JSON 한 덩어리. 서버·계정 없음.
- **schema 8** 예:
```json
{"schema":4,"unlocked":15,"cleared":{"dewdrop":true,"sprout":true},"noAds":false,"gold":240,
 "settings":{"sound":true,"vibration":true,"fastFx":false,"lang":"ko"},
 "skins":{"pieces":{"daisy":[0,3],"tulip":[0,1,2,3]},"equipped":"tulip"},
 "items":{"count":{"slot":2,"shuffle":2,"bloom":0},"unlocked":["slot","shuffle"],"tutorialDone":["slot","shuffle"]},
 "x2":{"ms":583000,"on":false},
 "lives":{"count":3,"anchor":1762311600000,"adDay":"2026-11-05"},
 "orders":["GPA.3312-1234-5678-90123"],"adPullDay":"2026-11-05"}
```
- `unlocked` = 다음에 할 스테이지(마지막까지 완성하면 1001). 해금 여부는 따로 저장하지 않고 "조각을 다 모았나"로 계산.
- 마이그레이션: schema 1(별점 → 1개 이상이면 완성) → 2(cleared·noAds) → 3(gold 0에서 시작) → 4(스킨 없음 = 기본 꽃) → 5(x2 10분·꺼짐, 아이템 0개. 해금 스테이지를 이미 지난 저장은 튜토리얼을 마친 것으로 치고 그 아이템 2개. 옛 "웨이브 속도" 설정은 버림) → 6(햇빛 5개 가득, 광고 충전 안 씀) → 7(지급한 주문 없음) → 8(무료 뽑기 안 씀).
  깨진 값·모르는 스킨·범위 밖 조각·음수 골드는 버리고 기본값. JSON이 깨졌으면 새 저장으로 시작.
- 저장 시점: 완성 기록·골드(완성 패널 전), 뽑기(연출 전), 장착, 광고 제거, 설정 변경, 아이템 해금·사용, x2 켜기/끄기, 햇빛 쓰기·돌려받기·채우기, 골드 구매 지급 즉시. x2 남은 시간은 5초마다·일시정지·화면을 떠날 때.

## 9. 레벨 생성기 (`lib/domain/generator.dart` + `tool/levelgen/`)

### 9.1 레벨 하나 만들기 (`generate`)
1. **그림 → 칸**: PNG 1픽셀 = 1칸(알파 < 128은 빈 칸). 색이 6개를 넘으면 가장 가까운 색끼리 합친다. 배율 s면 s×s 칸(본편은 한 변 32·전체 800칸 안에서 가장 큰 배율 1~3).
2. **시작 발아 지점**: 8방향으로 이어진 덩어리마다 1개 + 설정 수만큼.
3. **구성적 순서**: 실제로 두어 보면서, 지금 퍼질 수 있는 색 하나를 골라 물방울 양(설정 범위, 혼자 퍼질 수 있는 최대치 이하)을 정해
   넣고 안정될 때까지 진행 → 모든 칸이 필 때까지 반복. 이 순서대로 두면 반드시 클리어된다.
4. **줄 나누기**: 순서를 3~4줄에 나눠 담는다(각 줄은 원래 순서의 부분열, 줄마다 최소 1개).
5. **난이도 올리기**: 물방울을 줄 안에서 앞당기거나 다른 줄로 옮겨 보고, **솔버가 클리어 가능을 확인**하고 (무작위 실패율·슬롯 압박)이
   나빠지지 않을 때만 받아들인다. 목표(슬롯 최대 점유 ≥ 3, 클리어율 ≤ 목표)에 닿거나 시도 횟수(노말 200, 어려움 600, 튜토리얼 0)를 다 쓰면 끝.
6. **측정**: 무작위 플레이 300판 클리어율 → 등급, 점수(0~100) = 실패율·슬롯 압박·색 수·물방울 수 조합.

### 9.2 팩 만들기 (`levelgen build`)
- 설정(`levels.config.json`) 한 줄마다 시드 1~6을 돌려 **설정한 등급이 나오는 결과**를 고른다(목표 클리어율에 가장 가까운 것).
  6시드로 안 나오면 물방울 크기를 **비율로**(×0.7 / ×1.3) 조이거나(너무 쉬움) 풀고(너무 어려움) 줄 수·시작점도 바꿔 최대 3번 더 시도. 끝내 안 나오면 경고.
- isolate 4개로 병렬, 결과는 스레드 수와 관계없이 바이트 단위로 같다. 1000스테이지 약 10분(4코어).
- 출력: `out/pack-01.json`(한 줄에 레벨 하나) → `assets/levels/`로 복사, `out/report.csv`(지표), `out/previews/`(시작 상태 PNG).
- `levelgen verify`: 칸 수·물방울 총량 = 칸 수·3줄 이상·빈 줄 없음·덩어리마다 시작점·**솔버로 클리어 가능·해법 재생 시 클리어**·id 중복 없음. 1000개 몇 초.
- `levelgen sheet out.png [접두어]`: 그림 목록을 한 장으로(검토용).

## 12. 알려진 한계 · 남은 일

1. **실기기 확인 안 함**: APK를 이 클라우드 환경에서 만들 수 없었다(Android SDK 다운로드 차단). 로컬에서 `flutter build apk --release`.
   광고·결제·효과음은 실기기에서 처음 동작한다.
2. **출시 전 교체**: AdMob 실제 ID(앱 ID + 전면 광고 단위 + 배너 광고 단위), Play Console `remove_ads` 상품, 업로드 키.
3. **그림은 플레이스홀더**(코드·텍스트로 그린 픽셀 아트). 문양 타일 24장은 서로 비슷해 보일 수 있다.
4. **아이템·x2 보충 수단 없음**: 아이템은 해금 때 3개(튜토리얼 후 2개), x2는 처음 10분뿐. 상점 판매·광고 보상 등은 아직 없다.
5. **x2 표기와 실제 배율**: 450ms → 300ms 라 실제로는 1.5배다(요청대로 예전 "기본" 속도를 x2 로 표기). 정확히 2배가 필요하면 `x2TickMs` 를 225로.
6. **밸런스 미조정**: 골드 10~30, 뽑기 100 → 대략 5스테이지에 1번 뽑기. 플레이 후 `gold.dart`·`gacha.dart`에서 조절.
7. **골드 사용처는 스킨 뽑기뿐**. 아이템(06 가이드 3장)·유료 재화는 없다. 골드를 돈으로 팔면 확률형 아이템 법규가 적용된다(06 가이드 4장).
8. 저장은 기기 로컬만(재설치하면 진행도·골드·스킨이 사라짐). 클라우드 저장 없음.
9. 판이 커져(최대 652칸) 칸 하나가 작다(32칸 판에서 약 12dp). 보드는 터치하지 않아 조작에는 문제없지만, 작은 화면에서 잘 보이는지 실기기로 확인 필요
