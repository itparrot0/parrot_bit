## 2. 저장 (스키마 3)

```ts
// save.ts
export const SCHEMA = 3;
export type SaveData = {
  schema: number; unlocked: number; cleared: Record<string, true>; noAds: boolean;
  coins: number;                       // 새로
  items: Record<ItemId, number>;       // 새로: { undo: 3, slot: 1, peek: 0 }
  settings: Settings;
};
// migrate(): coins 가 숫자가 아니면 0, items 는 아는 id 만 0 이상 정수로. schema 2 저장은 그대로 올라온다.
```

- 코인·아이템은 **기기 로컬 저장**이라 조작이 쉽습니다. 유료 재화가 커지면 서버 검증(영수증 확인)이나 클라우드 저장을 검토하세요.
- 유료로 산 코인은 재설치하면 사라지므로, 소모성 상품은 "기기에 저장됨"을 상점에 안내하는 것이 좋습니다.

## 3. 아이템 효과 (GameController)

| 아이템 | 효과 | 구현 위치 |
|---|---|---|
| 이어하기 | 실패 직전 상태에서 슬롯 하나를 비우고 계속 | core 에 `clearSlot(state, i)` 추가. 실패 오버레이에 버튼 (되돌리기 기능은 2026-11-04 삭제됨) |
| 슬롯 +1 | 이번 판만 활성 슬롯 5칸 | `state.slots.push(null)` 후 `judge` 재계산. 레이아웃에 5번째 슬롯 자리 필요 → `DropView` 가 `slots` 배열 길이를 따르도록 |
| 줄 미리보기 +1 | 이번 판 `visible` +1 | 표시 전용이라 `DropView` 를 다시 만들면 끝 (규칙 영향 없음) |
| 섞기 | 한 줄의 남은 물방울 순서 섞기 | core 에 `shuffleLane(state, lane, rng)` 추가 (규칙 엔진 쪽 함수) |
| 힌트 | 지금 넣을 줄을 알려 줌 | 이미 있음 (`hint()`), 횟수 제한을 아이템으로 |

원칙: **규칙을 바꾸는 효과는 core 에 함수로**, 화면은 결과만 그립니다(지금 구조와 같음).

## 4. 상점 · 뽑기

- `ShopScene` 은 `SettingsScene` 과 같은 방식(Pixi 버튼 목록 + `ScrollView`)으로 만들고, 타이틀과 스테이지 맵에 상점 버튼을 둡니다.
- 뽑기 확률표는 `economy/gacha.ts` 의 상수 하나로 관리하고, **상점의 "확률 보기" 화면이 같은 상수를 그대로 읽어** 보여 주게 합니다(표시와 실제가 어긋나지 않게).
- 뽑기 난수는 `Math.random` 대신 시드가 있는 RNG(core 의 `mulberry32`)로 두면 테스트가 쉽습니다.

### 법적 주의 (한국)
- **확률형 아이템 확률 공개 의무**: 게임산업진흥법 개정(2024-03-22 시행). 유료로 얻는 확률형 아이템은 종류와 확률을 게임 안·누리집·광고에 표시해야 합니다. 유료 재화로 산 코인으로 돌리는 뽑기도 해당합니다.
- 청소년 결제·환불 정책, Google Play 의 "확률형 아이템 확률 공개" 정책(전 세계 적용)도 같이 확인하세요.
- 결제·광고가 늘면 Play Console 데이터 보안 양식, 콘텐츠 등급 설문("디지털 구매", "무작위 아이템")을 다시 작성해야 합니다(05 지시서).

## 5. 결제 (billing.ts)

- 지금은 `remove_ads`(관리형) 하나이고, 웹에서는 개발용으로 바로 지급됩니다. 네이티브 어댑터(cordova-plugin-purchase 또는 RevenueCat)를 연결해야 실제 결제가 됩니다.
- 코인 묶음은 **소모성** 상품으로 추가하고, 결제 완료 → `save.addCoins(n)` → 구매 확인(acknowledge/consume) 순서를 지킵니다. 확인을 빠뜨리면 3일 뒤 자동 환불됩니다.

## 6. 추천 순서

1. 저장 스키마 3 + `economy` 모듈 + 테스트 (화면 없이)
2. 완성 보상 코인 + 게임 화면 아이템 2종(이어하기, 줄 미리보기 +1)
3. 상점 화면(코인으로 아이템 구매)
4. 유료 코인 상품 + 네이티브 결제 어댑터
5. 뽑기 + 확률 공개 화면 (마지막, 법적 검토 후)
