## reference/ — 이미 동작하는 규칙 엔진·솔버·레벨 생성기
기획서의 규칙을 TypeScript로 옮긴 참조 구현입니다. 빌드 없이 Node 22.18 이상에서 바로 실행됩니다.

```bash
cd reference
npm test                                  # 규칙·생성기 테스트 9개
npm run demo -- mushroom 1 1 1 4 150      # 레벨 생성 + 클리어 수순(넣기/기다리기)을 텍스트로 재생
npm run demo -- mushroom 1 1 1 4 150 1 0  # 비교: 웨이브가 멈춘 뒤에만 탭
npm run sweep                             # 규칙 변형별 난이도 분포 측정 (약 15초)
```
demo 인자: `아트이름 시드 시작지점수 물방울최소양 최대양 순서흔들기횟수 [queuePick 기본 1] [realtime 기본 1]`. 아트는 `tulip`, `mushroom`, `sunflower` 중에서 고릅니다.

| 파일 | 내용 |
|---|---|
| `src/engine.ts` | 규칙 엔진: 틱 단위 링 웨이브, 8방향 전염, 슬롯, 클리어/실패 판정. 선택지 옵션(`queuePick`, `realtime`) 지원 |
| `src/solver.ts` | DFS + 실패 상태 메모 솔버, 무작위 플레이 클리어율, 슬롯 점유 측정 |
| `src/generator.ts` | 구성적 대기열 생성 + 검증된 언덕 오르기로 난이도 조절 |
| `src/arts.ts` | 샘플 픽셀 아트 3종 |
| `src/engine.test.ts` | 맨 앞 탭, 한 링씩 확산, 8방향 순서, 남은 양, 실패 조건, 생성 레벨 클리어 보장 테스트 |
