# 칸 애니메이션 에셋 (디자이너용) — 파일 위치 `assets/anim/`

게임 보드의 칸 하나하나가 이 그림으로 그려진다. **파일을 같은 이름으로 덮어쓰기만 하면 게임에 바로 적용된다** (코드 수정 없음).
지금 들어 있는 파일은 코드로 만든 임시 견본이다. 색을 입혀 재생한 모습: [cell_anim_preview.gif](cell_anim_preview.gif).

## 파일

| 파일 | 내용 | 프레임 |
|---|---|---|
| `seed.png` | 씨앗 칸 (정지) | 1 |
| `sprout.png` (+ `sprout_light.png`) | 발아: 씨앗 → 싹. **마지막 프레임 = 싹 칸 정지 모습** | 자유 (지금 8) |
| `bloom_<스킨>.png` (+ `_light.png`) | 개화: 싹 → 꽃. 스킨마다 한 벌. **마지막 프레임 = 꽃 칸 정지 모습** | 자유 (지금 8) |
| `full_<스킨>.png` (+ `_light.png`) | 완성 마무리 연출의 개화 → 만개. 스킨마다 한 벌. **첫 프레임 = 개화 정지 모습, 마지막 프레임 = 만개 모습** | 자유 (지금 10) |
| `anim.json` | 시트별 한 프레임 길이(ms) | |

스킨 id: `basic`(기본 꽃) · `daisy`(데이지) · `tulip`(튤립) · `sakura`(벚꽃) · `sunflower`(해바라기) · `clover`(네잎클로버).
`bloom_<스킨>` 의 시간은 `anim.json` 에 그 이름이 없으면 `"bloom"` 값을 쓴다. 파일이 없는 시트는 코드 견본으로 대신 그린다.

## 그리는 법

- **한 프레임 = 정사각형 한 칸** (권장 128×128). 프레임을 **가로로 이어 붙인** 한 장 → 프레임 수 = 가로 ÷ 세로.
- 칸 바탕(타일)까지 프레임 안에 그린다. 프레임 바깥은 잘리므로 튀어나오는 연출도 정사각형 안에서.
- 레이어 두 장:
  - **기본 파일(tint)** — **회색조로 그린다.** 게임이 칸 색을 곱한다: 흰색 = 칸 색 그대로, 50% 회색 = 절반 밝기, 검정 = 검정. 레벨마다 색이 달라 색을 넣어 그리면 안 된다.
  - **`_light` 파일(선택)** — 색을 입히지 않고 그대로 위에 얹는다. 반투명 흰색 하이라이트, 꽃 모양, 반짝임 등 칸 색보다 밝아야 하는 부분. (색을 넣으면 그 색 그대로 보인다)
  - 두 장의 크기·프레임 수가 같아야 한다.
- 투명(알파)을 쓸 수 있다. 프레임 사이 크기가 바뀌지 않게, 같은 자리에 맞춰 그린다.

## 시간 규칙

- 재생 길이 = 프레임 수 × frameMs. **360ms 이하**(기본 속도 틱의 80%)를 지킨다. x2 속도 예산은 240ms라 짧을수록 좋다. 지금 견본: 8 × 32ms = 256ms.
- 한 틱에 링 전체(수십 칸)가 조금씩 시차(칸당 최대 40ms)를 두고 동시에 재생된다.
- 끝나면 마지막 프레임에 머문다. 반복(loop)하지 않는다.

## 확인

```
flutter test test/ui/cell_sprites_test.dart          # 파일 규격 확인
flutter test tool/anim_export_test.dart --dart-define=ONLY_PREVIEW=true
                                                     # 지금 PNG 로 docs/anim/cell_anim_preview.gif 다시 만들기
```
`flutter test tool/anim_export_test.dart` (ONLY_PREVIEW 없이)는 **코드 견본으로 PNG 를 덮어쓴다** — 디자이너 파일을 넣은 뒤에는 쓰지 말 것.
