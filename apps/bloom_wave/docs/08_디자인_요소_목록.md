# 08. 디자인 요소 목록 — 디자인 교체 작업용 (2026-11-05)

지금 앱의 모든 시각 요소를 빠짐없이 적었다. 지금은 전부 **코드로 그린 임시 그림**(도형·Material 아이콘·기본 글꼴)이다.
디자이너 아트로 바꿀 때 이 표의 번호로 부른다.

- **🎞 = 애니메이션이 필요한 요소.** "지금" 칸은 현재 코드 연출(교체 시 참고할 시간·움직임), "요구"는 새 아트에서 필요한 것.
- 모든 크기는 **논리 해상도 1080×2340** 기준(화면에 비율 유지로 맞춤, 폰에서 논리 1 ≈ 0.38dp).
- 코드 위치: `lib/ui/`(공통), `lib/game/`(보드·연출), `lib/screens/`(화면).

## 0. 교체 전에 알아야 할 제약

| 항목 | 내용 |
|---|---|
| **칸 그림은 흰색(회색조)으로** | 레벨마다 팔레트가 달라(색 최대 6개, 그림 463장) 칸 바탕·씨앗·싹·꽃은 **흰색으로 그리고 코드가 색을 입힌다**(tint). 색이 들어간 칸 그림은 쓸 수 없다. 명암만 회색조로 주면 색과 곱해진다 |
| **칸 크기 범위** | 판 크기에 따라 한 칸이 **약 31px(32×32칸 판) ~ 130px(7×7 튜토리얼)**(논리). 원본은 128×128 기준, 31px에서도 형태가 읽혀야 한다 |
| **동시에 움직이는 칸 수** | 한 틱(기본 450ms, x2 300ms)에 **링 전체가 한꺼번에** 개화(수십 칸) + 그 이웃이 발아. 판은 최대 652칸 |
| **칸 애니메이션 시간 예산** | 한 틱의 연출은 **다음 틱 전(틱의 80%)** 안에 끝나야 한다: x2 기준 240ms, 기본 360ms. 지금 칸 애니메이션은 260ms + 시차 |
| **애니메이션 형식 (구현됨)** | 칸 씨앗·발아·개화는 **스프라이트 시트**(`assets/anim/`, 128px 프레임을 가로로 이어 붙임). 회색조 tint 레이어 + 선택 `_light` 레이어. 파일을 덮어쓰면 바로 적용. 규격: **`docs/anim/README.md`**, 미리보기: `docs/anim/cell_anim_preview.gif` |
| **물방울 숫자** | 물방울 위의 크기 숫자(최대 두 자리, 최대 30)는 **코드가 글자로** 그린다. 물방울 그림에 숫자 자리를 비워 둔다. 밝은 물방울(흰색·노랑)에서는 숫자가 어두운 색으로 바뀐다 |
| **물방울도 흰색으로** | 물방울 색 = 그 그림의 칸 색. 물방울 그림도 흰색 + tint |
| **텍스트** | 모든 문구는 한국어/영어 두 벌, 코드의 글자(`lib/i18n/strings.dart`). 이미지 속 글자 금지(로고 제외) |
| **글꼴** | 지금 시스템 기본(안드로이드 Roboto/Noto Sans KR). 제목·숫자용 글꼴을 따로 지정할 수 있다(파일 제공 시) |

**칸 애니메이션 기술 메모 (2026-11-05 구현)**
- 보드는 상태(씨앗·발아·개화)별 시트마다 `drawRawAtlas` 한 번(+ light 한 번)으로 모든 칸을 그린다. 칸 색은 tint 레이어에 곱해지고(modulate), 프레임 = (지금 − 그 칸이 바뀐 시각) ÷ frameMs, 끝나면 마지막 프레임.
- 시트는 앱 시작 때 뒤에서 불러 두고(`lib/ui/cell_sprites.dart`), 준비 전이나 파일이 없으면 코드 그리기·코드 견본(`cell_sprites_gen.dart`)으로 대신한다.
- 같은 링에서 피는 칸들은 시차를 두고 차례로 시작한다 → 애니메이션 길이 + 시차가 틱의 80%(기본 360ms, x2 240ms)를 넘지 않게.
- 완성 반짝임(4-8)·미리보기 흐림/테두리(4-6)는 시트 위에 코드로 얹는다. "빠른 연출" 설정은 시차·물줄기·꽃잎만 끈다.
