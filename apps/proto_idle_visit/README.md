# proto_idle_visit (놀러 와요 — 프로토타입)

방치형 힐링 캐릭터 수집 프로토타입. 장소의 자리마다 아이템을 놓아 두면, 시간이
지나면서 그 아이템을 좋아하는 캐릭터가 무작위로 찾아온다. 만난 캐릭터는 도감에
쌓인다.

- 기획·규칙: [`docs/prd/proto_idle_visit.md`](../../docs/prd/proto_idle_visit.md)
- **기본값은 폐기다.** 승격 시 `apps/<정식이름>`을 새로 만들고 검증된 코드만
  이식한다 (`docs/03-architecture.md` §6).

## 구조

```
lib/
├── domain/                순수 Dart. Flutter 없이 테스트된다
│   ├── catalog.dart           장소·아이템·캐릭터 데이터 + 무결성 검사
│   └── world.dart             배치·추첨·방문·도감·시간 진행·JSON 저장
├── data/world_repository.dart core_storage에 저장/불러오기 (+ 오프라인 진행)
└── main.dart              화면 — 장소 탭(자리 카드) / 도감 탭
```

**시간은 `World.advance(now)`로만 흐른다.** 앱이 켜져 있으면 1초마다, 다시 열면
한 번 부른다. 둘의 결과가 같다는 것을 테스트가 고정한다.

## 화면

- **장소 탭** — 마당/창가 칩으로 장소를 고른다. 빈 자리 `+ 놓기`를 누르면
  아이템을 고르고, 놓인 자리를 누르면 바꾸거나 치운다. 손님이 있으면 아이템 위에
  캐릭터가 앉고 남은 시간이 보인다.
- **도감 탭** — 만난 수 / 전체. 못 만난 캐릭터는 `❔ ???`와 희귀도만.
- 상단 **`+30분`** — 개발용 빨리 감기. 앞당긴 시간은 저장되므로 재시작해도
  시계가 뒤로 가지 않는다.

## 실행

```sh
flutter pub get                            # 저장소 루트에서 1회
cd apps/proto_idle_visit && flutter run
flutter test                               # 이 앱만
```
